## 修复"改了选区不生效"（贴边把手抓不到）
- 现象：用户改了选区但 masks.json 还是旧值 → 前端拖拽根本没触发保存。后端本来就是每帧 mask_rects() 动态读，不是"不动态"。
- 根因：m4/m3 等选区贴画面边缘(x2=1.0/y2=1.0)，把手在画面边界像素上，事件落不到 canvas（元素边界外）。
- 第一版修复（canvas 外扩 PAD=10px）无效：.tile 是 overflow:hidden 且画面占满 tile，外扩部分全被裁掉。
- 最终修复：DOM 重构——新增 .tileWrap(position:relative) 包住 .tile，canvas 和 grip 移出 tile 成为 wrap 的子元素；canvas 尺寸=tile+2*PAD、不裁剪；坐标换算用 L.ox/L.oy（PAD+黑边）；editing 类切换到 tileWrap；grip 在 DOM 中排在 canvas 后仍可用。
- 教训：给被 overflow:hidden 裁剪的容器内元素外扩命中区是无效的，要把可交互层提升到不裁剪的父级。

- 关键技巧：遮罩层需要四周外扩 PAD=10 才能抓到贴边把手，但外扩会撑出横向滚动条 → `.tileWrap{margin:0 -10px; padding:10px}`，负 margin 抵掉余量，画面宽度仍等于卡片内容宽度，canvas 左/上 = tile 左/上 - 10（用 getBoundingClientRect 相减，不再用 offsetLeft，因为 wrap 有 padding 后 offsetLeft 不可靠）。
- 面板改为图片下方：`.rows` 用 grid auto-fit minmax(150px,1fr)（1366 下 8 列），按钮 @media(min-width:720px) 时 flex:0 0 auto 不拉满，过滤框 max-width 420。
