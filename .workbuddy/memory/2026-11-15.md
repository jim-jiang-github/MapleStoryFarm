### 踩坑：import 期起线程 → NameError 把线程带走（已修）

- 现场：`启动预览.bat` 里控制台打印 `Exception in thread lietrack: NameError: name
  '_game_foreground' is not defined`。服务本身起来了（页面能开），但追踪线程**死了**，
  面板永远「待命」。
- 原因：`lietrack.start()` 写在 server.py 模块顶层，而 `foreground=lambda: _game_foreground()`
  指向的 `_game_foreground` 定义在文件后面（约 2450 行）。线程一跑第一轮就调它 → 名字还
  没绑上。**别在导入期启动任何会回调本模块函数的线程。**
- 修法：`start()` 挪进 `__main__`（`_start_lietrack()`，uvicorn.run 之前）；另外 `LieTrack.run()`
  拆成 run/_run_loop，单轮异常只记 `status.error` 再重开一轮，**不再让线程静默退出**。
- 教训：`MAPLE_HEADLESS` 下不起线程这条设计掩盖了这个 bug——单测与无头自检全绿，真起服务才炸。

### 语义调整：关键词只管「起跑」，跑满 run_sec 才松手（用户要求）

- 用户原话：「不要停止跟随，启动跟随之后 15 秒之后再自动关闭就好了」。
  旧逻辑是关键词消失 `hold_sec` 后就松手（实测每次触发只跑了 2 帧检测就撒手，鼠标几乎没动）。
- 新逻辑：`present` 命中 → `_until = now + run_sec`（默认 15s，面板可改 1~120）→ 窗口内一直跟，
  关键词消失/`tracker.state==LOST` 都**不**收摊（LOST 时 `tracker.reset()` 回 INIT 等中心重捕）→
  时间到才 `_release`。另加 `_wait_clear`：跑满时关键词若还在画面上，必须等它先消失才允许再触发，
  否则会变成无限续杯。`hold_sec` 降级成「只影响面板那行字的显示」。
- `status.run_left` 给面板倒计时用（跟随中显示「剩余 Ns」）。
- 测试从 21 项加到 22 项：`test_triggers_and_releases` 改成验「关键词消失仍继续跟、跑满才松」，
  新增 `test_lost_target_keeps_running`（检测全空也要跟到时间到）。

### 启动慢的两次修正（用户问「启动为什么要很久」）

- 实测拆账：bat 里的 import 探测 **3.9 s**（`import ultralytics,openvino` 本身 3.0 s）+
  到端口可访问 **3.3 s** + 后台预热模型 5.7 s（import 2.3 + OpenVINO 首帧 3.3，与前者并行）。
- 改 1：`启动预览.bat` 去掉 import 探测，改成「固定路径存在就用，否则退回 PATH 里的 python」。
  该 bat 是 GBK+CRLF 且底部还有乱码注释，**改它必须按字节改**（Latin-1 映射读写，只在 ASCII 区内替换，
  中文注释一律别写进去——Latin-1 编码会把中文变成 `?`）。实测 bat → HTTP 200 从 ~7.2 s 降到 **3.5 s**。
- 改 2：server.py 里自动开页面从 `threading.Timer(1.2)` 改成「轮询端口到真的 bind 再开」。
  原写法比 uvicorn bind 早 2 秒，用户先看到「无法连接」，主观上就是「没启动成」。
- 教训：清理测试进程时不要用 `*server.py*` 模糊匹配去 kill——会把正在跑的主服务一起杀掉（这次就误杀了）。
- 补：`$pid` 在 PowerShell 里是只读变量，存进程号会直接报 `Cannot overwrite variable PID`。

  `trigger=ocr` 那段旧路径保留可回退。中文路径必须 `cv2.imdecode(np.fromfile(...))`，`cv2.imread` 返回 None。

- `LieTrack.warmup()`：读模板 + 装 lietrack 的 YOLO（+OCR），由 `_start_lietrack()` 起**后台线程**跑，
  实测 6.0 s 完成、和启动并行，不挡页面。`GET /api/lietrack` 加 `tpl_ok`。
- 测试 28→29 项：`TestTemplateTrigger`（默认走模板、贴回定位 (300,200)、空画面不误判、0.9 缩放仍 >0.7、
