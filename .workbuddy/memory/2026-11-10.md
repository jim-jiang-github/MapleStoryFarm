
## 技能框编辑三连修（7048d3f）

用户实测反馈三问题 → 修复方案（后续改技能编辑时别走回头路）：

1. **确认收尾**：编辑中「画面调整」按钮变「✓ 完成」（高亮），点击/Esc 收起
   并 toast 已保存范围值；画面顶部常驻操作提示条。
2. **实时跟随**：锚点=人物身体中心实时值（rAF 循环重绘 drawMasks），
   拖动那一会儿冻结在 pointerdown 时刻（drag.anchor）防框漂移；
   没定位到人物 → 画面中心偏下 (W/2, H*0.62) 兜底，照样能编辑。
   关键函数：skillAnchorLive / skillAnchorNow / skillLoop。
3. **显式方向 dir**：both 左右 / front 身前 / left 仅左 / right 仅右。
   skill_rects 用 _dir_extents 裁半边；one_sided 改读 dir（不再靠框形状猜）；
   旧 range_side=front 迁移进 dir。front=感知两侧+出手前转身对正；
   left/right=另一边的怪压根不进判定（走路目标也只认活动半边的带）。
   server 画框：front 只画当前朝向半边带 -> / <- / ? 箭头。
   编辑画面：锚点竖虚线分界、不活动半边压暗、front 两侧标
   「朝左/朝右时打这边」。

测试：test_bot 107/107，test_headless 66/66（新增仅右/身前两条方向用例）。
